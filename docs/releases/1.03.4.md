# Droide 1.03.4 — private candidate

Android package `com.baystudio.droide`, version name `1.03.4`, version code `51`. The baseline for upgrade testing is the published 1.03.3 build (50).

## Changes under test

- Replace and Replace All insert the requested text literally, including brackets and quotes. One Undo reverts Replace All.
- Chat drafts are kept per conversation. External agent prompts are written to private storage before acceptance so an interrupted prompt can be reviewed before resending.
- Project-aware TypeScript lint, terminal output containing Unicode, streamed provider responses and cancellation of Android folder reads have targeted fixes.
- The optional Ubuntu downloader can try a pinned alternative when the primary URL reports a missing file. The download still requires integrity verification.

## Build and upgrade testing

For an in-place upgrade from the production app, Android requires an APK signed with the original production certificate. An unsigned build requires signing before installation. Use a separate test installation for a build signed with another key. The latest public release and its signing records are documented separately.
