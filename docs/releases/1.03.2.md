# Droide 1.03.2

## Changes

- Extensions can retry a cancelled installation after cleanup. Installations reuse the active Ubuntu environment and prepare required libraries before checking the installed tool.
- Run resolves compilers and interpreters in the project's Ubuntu environment. TypeScript and Prettier can use the dependencies installed by the project.
- **Lint file** checks supported source files through the IDE or the built-in agent. **Android Lint** runs the Gradle project check.
- The built-in handbook opens the Agent, Architecture and Integrations topics. It includes dedicated setup guidance for 9Router. [9Router setup](../guides/custom-providers.md#9router)

## Download and upgrade

Install **Droide-1.03.2-release.apk** over an earlier GitHub production release to update in place. Droide 1.03.2 uses version code 49 and the original BayStudio production certificate. Android 10 or later is required. The optional Ubuntu environment runs on ARM64. [GitHub release](https://github.com/baystudio-dev/Droide/releases/tag/v1.03.2)

Debug builds use a separate signing certificate. Export projects and any private data you need before removing a debug installation. Android removes the app's private data during uninstall.

The release includes source, SHA-256 checksums and the public signing certificate. [Build and signature verification](../distribution/signing.md)
