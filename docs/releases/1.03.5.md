# Droide 1.03.5

Android package `com.baystudio.droide`, version code `52`. This update follows GitHub release 1.03.4 (51).

## Changes

- Connect Droide to a 9Router server on the same trusted LAN. Choose **9Router** in provider settings and enter the server’s private IPv4 address and port. If you use HTTP, the API key and prompts travel in cleartext on that network. [9Router connection guide](../guides/custom-providers.md#9router)
- Open **Settings → About & Legal → Support Droide** for voluntary donations. Open the Bayyy page on SociaBuzz or scan the QRIS for **Baystudio, Konter**. **Save QRIS to gallery** lets you select the image in a payment app on the same phone. In Indonesian, search Settings for **donasi** or open **Dukung Droide**.

## Download and upgrade

On Android 10 or later, open **Droide-1.03.5-release.apk** and choose **Update**. The official 1.03.4 APK and the production-signed 9Router and donation test builds (51) use the same signing certificate. Android can update those installations in place and retain their app data. [GitHub release](https://github.com/baystudio-dev/Droide/releases/tag/v1.03.5)

The release provides an official source archive, public signing certificate, verification report and SHA-256 checksums. Use the tagged Git checkout to reproduce the APK with its embedded source revision. [Build instructions](../distribution/fdroid.md#build) · [Signature verification](../distribution/signing.md)
