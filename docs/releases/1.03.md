# Droide 1.03

## Changes

- Pinch to zoom or pan across the agent’s desktop browser preview while the agent continues at its original resolution. Double-tap to zoom and use Fit to see the full page again. The agent opens a separate tab by default. Sharing a personal tab is an explicit choice for that chat.
- The browser follows nested video feeds and can save supported website downloads to Android Downloads after confirmation. Scroll, drag, double-click and press-and-hold use the current page geometry.
- Droide recognizes an existing Ubuntu installation after reopening the app. Setup checks downloads against the signed artifact metadata and can retry a failed integrity check.
- External CLI sessions can recover after an interrupted run. The Android SDK installer handles larger official archives, and Gradle can reuse up-to-date outputs for repeated builds.
- Settings adapts to screen width and text size. Under **Settings → Editor**, you can restore the Android status bar and reserve its space. The editor opens in immersive mode by default.
- Editor synchronization preserves unsaved work through temporary storage access failures. Language associations, syntax highlighting and MCP tool discovery have been updated. Long agent sessions retain their history across reopening and forks.
- Explicit Exit closes as soon as recovery finishes. A five-second deadline also covers a stalled shutdown.

## Download and upgrade

Download **Droide-1.03-release.apk** from the [1.03 release](https://github.com/baystudio-dev/Droide/releases/tag/v1.03). It targets Android 10 and later. The optional Ubuntu environment requires ARM64.

Users of a production-signed Droide release can install 1.03 over their existing app. Android checks the package identity and signing certificate during the update. If you installed a test APK signed with a debug key, export your projects and other data you need before switching. Removing the test app also removes its private data.

The release includes checksums and the public signing certificate. Build and signature verification are documented in the [signing guide](../distribution/signing.md).
