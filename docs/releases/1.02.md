# Droide 1.02

Package: `com.baystudio.droide` · Version code: `46` · Android 10 or newer.

## Download and upgrade

Download the production-signed APK from the [GitHub release](https://github.com/baystudio-dev/Droide-v1.-00/releases/tag/v1.02). It uses the same signing identity as the GitHub 1.00 release. Install the update over the existing production installation to preserve application data and the installed Ubuntu environment.

Development-signed APKs and independently signed distributions use different certificates. Preserve projects and other private data before switching signing channels; uninstalling removes private application data. An unsigned APK is a build-review artifact and cannot be installed directly.

## Changes

- Optional **Access shared files** connects permitted Android shared storage to the terminal and agents. Users enable the setting and grant Android file access explicitly. New terminal and CLI sessions receive the updated mount configuration.
- **Show project in Android Files** exposes saved project files through Android's document provider. Save editor changes first; this view is read-only. Explorer export remains available for sharing complete files and folders.
- Terminal **Commands** explains both storage options, their settings paths and when a terminal or CLI session needs reopening.
- The agent handbook provides bounded, current storage, SSH, environment and Android-device guidance. Built-in and external agents use the same section registry.
- The workbench retains the current editor, terminal, Explorer and external-agent synchronization repairs, including Run File targeting, concurrent file changes and launch diagnostics.
- Contributor documentation is organized into feature guides and ownership contracts. Relevant regression tests, dependency verification and original third-party notices remain included.

Ubuntu and development tools remain on demand. The application asks before the first environment download and reuses a healthy installation and user packages. Ubuntu requires an ARM64 process. Shared-file access requires Android 11 or newer; Android 10 retains the supported picker/export workflows.

## Source and verification

The release source archive and immutable `v1.02` tag identify the source used for the APK. Source exports exclude generated build output, unused legacy binaries, compiler bundles, root filesystem images and private signing material. The application and native components build from corresponding source with locked, verified dependencies.

Follow the [source build procedure](../distribution/fdroid.md) with `--device-storage` to preserve the release feature set. Build output includes release lint, APK/native integrity checks and independent native rebuild comparisons. The release assets include checksums, the public certificate and verification records for the exact source and APK. Host checks and earlier device tests do not establish physical-device testing of a different APK; consult those records for the measured scope.


F-Droid packaging uses the matching source recipe and a separate review process. A local build or GitHub release does not imply F-Droid acceptance. Previous releases and their source tags remain available for reference.

## Reporting problems

Use the [issue tracker](https://github.com/baystudio-dev/Droide-v1.-00/issues), including the installed version, Android/device details, reproduction steps and the exact error. Remove credentials and private project content from attachments. Preserve recovery drafts and existing projects while investigating an update failure.
