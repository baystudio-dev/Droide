# Droide 1.03.6

Android package `com.baystudio.droide`, version code `53`. This release follows 1.03.5 (52).

## Changes

- When a terminal command or another editor changes a file after an external agent reads it, ACP asks the agent to read the current version before writing. The chat history shows which files were written before a session stopped.
- Git Discard and Explorer Delete recheck the selected file when you confirm. An isolated agent merge checks for conflicts before updating the parent project. A commit requested by the built-in agent waits for its pending editor edits to be saved.
- Project commands start in the selected project even if the shell’s last directory moved. Explorer keeps loaded pages and refreshes visible search results after relevant changes. An open Git panel picks up staging changes made from the command line.
- Reading background job status reuses its completion result. Checking the workspace keeps inactive editor tabs unloaded. Opening another tab preserves a pending save to an Android linked folder, and a saved local copy can be retained when the storage provider is temporarily unavailable.

## Download and upgrade

On Android 10 or later, download **Droide-1.03.6-release.apk**, open the file, and choose **Update**. The official 1.03.5 APK and the production-signed workspace synchronization test APK use the same Android package and certificate, so Android can update either installation in place.
