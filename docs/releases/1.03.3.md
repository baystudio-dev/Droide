# Droide 1.03.3

## Changes

- Typing ordinary words in the agent composer allocates less temporary memory. The editor reuses a buffer for syntax and semantic colours, and the Stop button reuses its shapes and animation settings.
- Restoring or forking older conversations preserves their available context. Git stash operations verify the entry selected and request confirmation before removal.
- File lint respects TypeScript project configuration and checks Go packages. Prettier uses project settings. Workspace search continues past exceptionally long lines and reports partial results.
- Language-server edits check document revisions before applying changes. Quick Fix reports the outcome in the active view. MCP resource, template and prompt listings can continue through multiple pages.

## Download and upgrade

The production APK is **Droide-1.03.3-release.apk**, package `com.baystudio.droide`, version code **50**. Android 10 or later is required. The optional Ubuntu environment runs on ARM64. Install the APK over the existing GitHub production build to retain the app's private data. You can compare the public signing certificate and the APK checksum before installing. [GitHub release](https://github.com/baystudio-dev/Droide/releases/tag/v1.03.3)

The 1.03.2 Performa test APK uses the Android debug certificate. Android checks the signing key during an update. If switching from that debug build, export the projects and data you need before uninstalling it. Uninstalling clears its private storage.
