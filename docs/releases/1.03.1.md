# Droide 1.03.1

## Changes

- Connect a 9Router instance from the provider menu. Droide accepts the server base URL or its model-list or chat-completions URL and discovers the model IDs exposed by that instance.
- In Extensions, search the catalog, open a tool to review its source and available versions, and return to the same list. Installation progress stays accessible while you browse.
- Installing another extension reuses an existing Ubuntu environment. For Kotlin installed through Ubuntu APT, the installation result identifies the installed package version and the version reported by the compiler. Ubuntu controls the version available through this route.
- Scrolling, transitions and streamed chat updates do less repeated work on the UI thread.

## Download and upgrade

Install **Droide-1.03.1-release.apk** over an earlier production release. This update uses version code 48 and the original BayStudio certificate. Android 10 or later is required. The optional Ubuntu environment requires ARM64. [GitHub release](https://github.com/baystudio-dev/Droide/releases/tag/v1.03.1)

Test builds use a separate signing key. Export any projects and other private data you need before removing a test installation. Android removes its private data when you uninstall it.

The release includes SHA-256 checksums, source and the public signing certificate. [Build and signature verification](../distribution/signing.md)
